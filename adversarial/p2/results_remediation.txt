Fix commit: 4d1ab6614bfcb103edb2d8cd721f63fdef0e96a4
Date: 2026-11-19 UTC

The fix applies count and aggregate-wire-byte limits in the shared async-imap
decoder before a parsed response escapes into a collector. The backend uses a
1,024-response, 64 MiB command budget, an 8 MiB individual-response limit and
a nesting limit of 64. Requested UID FETCH consumers additionally enforce
requested cardinality and reject duplicates. Large flag reconciliation is
performed in exact 512-UID chunks.

  requested=40000 rejected=true error=Io(Custom { kind: Other, error: "incoming command exceeds configured response-count limit" }) peak_rss_kib=6672
  exit=0 external_peak_rss_kib=28616 address_space_limit_kib=none
